# Lexico-Semantic Effects Conceptualization Drift

This repository contains the datasets, prompts, generated workbooks, evaluation code, and derived analysis artifacts for evaluating LLM-generated queries over two KG conceptualizations.

## Directory and File Overview
* **datasets/** - Schema and KG data.
* **evaluation_dependencies/** - Dependency tables for checking and alignment.
* **evaluation_results/** - Generated model workbooks and rubric workbooks.
* **prompts/** - Prompt templates used for LLM query generation.
* **scripts/** - Generation, checking, evaluation, and helper scripts.
* **analyses/** - Checked-in derived final-paper outputs.
* `requirements.txt` - Python dependencies.
* `LICENSE` - Repository license.
